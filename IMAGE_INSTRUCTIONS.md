# Storefront Photo Replacement

The website now uses **one main storefront image file** everywhere the real shop photo appears.

## Replace this file

- `public/images/hero-store.jpg`

## Where it appears

- Hero section
- About section
- Gallery (Store photos)
- Social sharing preview image

## What to do

Save the real Om Kapgate Agency storefront photo as:

`public/images/hero-store.jpg`

Then run:

`npm run build`

That single file will update all main storefront visuals automatically.
